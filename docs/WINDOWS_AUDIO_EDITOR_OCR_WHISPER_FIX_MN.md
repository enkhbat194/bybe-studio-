# BYBE Studio — 2026-11-15 Windows дээрх бодит засварын хуудас

Эх код: https://github.com/enkhbat194/bybe-studio-/tree/feature/typography-ocr-workstation

## 1. Илэрсэн алдаа / засвар
- OCR олон санамсаргүй 1 үсэг, усан тэмдэг, нүүрэн дээрх дүрсийг бичвэр гэж таньсан. Tesseract-ийн confidence (найдвартай байдлын оноо), бичвэрийн хэмжээ/байрлал/Unicode шүүлтүүр нэмсэн. Видео дээрх координатын хайрцгууд **зөвхөн T (текст холбох) горимд** харагдана. Өмнөх OCR job-д хуучин өгөгдөл үлдсэн бол «↻ OCR дахин таних» дарна. Шинэ шүүлтүүр ч 100% алдаагүй биш.
- Засварын popup өмнө нь `originalStart-2` — `originalEnd+2` секундийн цонхтой байсан. Одоо үндсэн эх аудионы дурын секундэд очих гүйлгэгчтэй, хүссэн хүрээгээр 0.5–600 секунд хүртэл zoom, хоёр чигт pan хийдэг.
- Popup «Сонсох/Давтах» өмнө нь эх видеог seek хийдэг байв. Одоо `/api/media/:id/listen?start=...&end=...` локал endpoint-оор бие даасан WAV сонсоно. Үндсэн видеоны курсорыг хөдөлгөхгүй, WAV revision үүсгэхгүй. Сонгосон хэсэг эсвэл харагдаж буй аудионы хүрээг сонсож болно; нэг удаагийн preview 300 секундээс урт биш.
- Доод master timeline одоо бүтэн файлын seek slider, хулганы дугуйгаар томруулах (64× хүртэл), Shift + дугуйгаар pan, Shift + чирж pan, хулганаар энгийн чирж хэсэг сонгох ажиллагаатай. Browser-ийн default wheel scroll-ийг зогсоох non-passive event listener ашиглаж байна.
- Local faster-whisper загварын `cublas64_12.dll` алдаа нь NVIDIA GPU дангаараа CUDA 12 runtime гэсэн үг биш. Windows-д BYBE `BYBE_ASR_DEVICE=cpu` (CPU) горимыг анхдагч болгосон. Хурд нь GPU-ээс удаан; GPU-г зөв суулгасны дараа тусад нь сонгож болно.
- Хуучин ASR алдааны бүртгэлд програм нэг удаа автоматаар дахин оролдоно.

## 2. Шинэ кодоо авах
CMD дээр одоо ажиллаж буй `npm run dev`-г Ctrl+C-аар зогсооно.

```bat
cd /d D:\bybe-studio\BYBE-new
git pull origin feature/typography-ocr-workstation
npm install
set BYBE_ASR_DEVICE=cpu
npm run dev
```

Chrome: `http://localhost:3000` → Ctrl+Shift+R → эх видеогоо дахин нээ.

## 3. Whisper суулгах / шалгах
```bat
py -3.11 --version
py -3.11 -m pip install --upgrade faster-whisper
py -3.11 -c "from faster_whisper import WhisperModel; print('Whisper импорт OK')"
```
Хэрэв гурав дахь команд хэвийн бол **Python сан суусан**. Энэ нь ASR загварыг татаад зургаан цагийн файлыг үнэхээр таньсан гэсэн нотолгоо биш. BYBE дээр CPU горимд эхний 5 минутын нэг хэсгийг таньж шалгана. Анх ажиллахад үнэгүй `small` модель татна (интернет шаардлагатай). CPU i7-10750H + RAM 16 GB орчинд удаан байж болно.

`INSTALL_WHISPER_WINDOWS.bat` нь дээрх суулгалтыг хялбарчилна. `START_BYBE.bat` нь `BYBE_ASR_DEVICE` өгөгдөөгүй бол CPU сонгоно.

CUDA-г санаатайгаар идэвхжүүлэх тохиолдолд CUDA/cuDNN runtime бүрэн суулгасан **дараа** нь `BYBE_ASR_DEVICE=cuda` гэж тохируулна. `cublas64_12.dll` алдаатай үед GPU-г хүчлэх нь буруу.

## 4. Аудио засварлах
1. Зүүн жагсаалтын мөрийн ✎ товч → том засварын цонх нээгдэнэ.
2. Дээд `Бүтэн бичлэгийн байршил` slider-аар 15 минут эсвэл 6 цагийн эх файлын дурын газарт очно.
3. `−` (хүрээ өргөсгөх), `＋` (нарийсгах), `←/→` (хөдөлгөх), mouse wheel (zoom), Shift+wheel болон Shift+drag (pan).
4. Хөх/шар босоо бариулыг чирж тухайн мөрийн эхлэл/төгсгөл тогтооно.
5. «▶ Сонгосон хэсгийг сонсох» эсвэл «▶ Дэлгэцийн хүрээг сонсох» → попап дахь audio тоглуулагч; давталт сонгож болно.
6. «Засвар хадгалах» дарахад шинэ хугацаа/текст хадгалагдаж, өмнө байсан QA цуцлагдана. WAV-г дахин экспортолж сонсож байж хүний 6 QA-г батална.
