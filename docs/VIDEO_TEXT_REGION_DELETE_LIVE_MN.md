# BYBE Studio — текст хүрээлэх, мөр устгах, нэг товшилтоор асаах (2026-11-15)

## Бодит асуудлууд ба хийсэн шийдэл
1. **OCR таньсан жижиг үгэнд л товшдог байсан:** Шинээр `VideoTextRegion.tsx`. Аудио сонгосны дараа видео пауз хийнэ. Видеоны бүхэл өгүүлбэрийг хулганаар тэгш өнцөгт хүрээлж сонгоно. Сонгосон хэсгийг эх видео кадраас canvas-аар тасалж, `/api/ocr-layout`-руу **локал Tesseract.js**-аар уншуулна. Үгийн эргэн тойрны зураг ба орчуулгын OCR хуурамч хэсэг нөлөөлөх магадлал буурна. Нэг мөр бус олон мөрийн OCR бичвэрийг нийлүүлнэ; богино/буруу үгийг хэрэглэгч текстийн талбарт засна.
2. **OCR огт уншаагүй бол:** Хүрээлэлгүйгээр ч T горимын текстийн талбарт Чех эсвэл Англи хэллэгийг гараар бичиж болно. Текстийг `⧉ Текст хуулах`-аар clipboard руу, `✓ Сонгосон аудиотой холбох`-оор сегмент дээр хадгална. Хуваарилалтын төрөл сонгоно. Аудио сонгогдоогүй бол анхааруулна, хугацаа зохиохгүй.
3. **OCR өгүүлбэрийн өнгө/үсгийн хэв маяг:** Энэ хувилбар үсгийн хэв жин/өнгө автомат мэддэг гэж амлахгүй; хүний засвар, sentence бүтэн тэмдэгт авах нь анхдагч.
4. **Буруу аудио мөр устгах:** Зүүн жагсаалт дээр `Trash` (хогийн сав) товч. Мөр сонгоод `Delete` буюу `Backspace`; `Ctrl+Z` буюу `Буцаах` сэргээнэ. Хавсаргасан AVI/MP4/MKV эх файл, өмнө экспортолсон WAV revision огт устахгүй. QA баталгаажсан мөрийг устгахад баталгаажуулалт асууна. Устгасан автомат санал browser-ийн хадгалсан tombstone-оор дахин гарч ирэхгүй. `JSON бүртгэл экспортлох` нь tombstone-г хамт хадгална.
5. **Shift + хулганы дугуй видеон дээр:** Видео тоглуулагчийн дээгүүр байхад арагш/урагш 1–9 секунд орчим алгасаж шилжинэ; кодын UI navigation не timeline-аас тусдаа.
6. **Whisper `cannot access local variable selected`:** `scripts/local_asr_worker.py`-д `selected = os.getenv(...)` мөр санамсаргүйгээр Python comment дотор орсон байсан. Бодит `transcribe()`-ийг fake WhisperModel-оор ажиллуулдаг `tests/python-worker-device-test.py` шинээр нэмсэн (CPU, auto, invalid). Хэрэглэгчийн файл дахь `Whisper OK`-оос faster-whisper Python импорт амжилттай гэж үзэж болно, дахин pip install шаардлагагүй.

## Хөгжүүлэлтийн LIVE горим: байнга Ctrl+C, npm install, git pull бичихгүй
**Нэг л удаа** өнөөдрийн өөрчлөлтүүдийг татаж, `START_BYBE_LIVE.bat`-ийг ажиллуулна. Түүнээс хойш BYBE-ийн тэр цонх ажиллаж байх хугацаанд `scripts/dev_live.mjs` нь 90 секунд тутам GitHub-ийн **зөвхөн `feature/typography-ocr-workstation` салбарын** шинэ commit-ийг татна. Зөвхөн `fast-forward`, local uncommitted source файл байвал *татахгүй*. Node watch серверийг, Vite HMR UI-г шинэчлэхийг хичээнэ. Интернет тасарвал хуучин код үргэлжилнэ. `main` салбар болон Google AI Studio-ийн unpushed 40 файл хөндөгдөхгүй.
**Анхаар:** Энэ нь хөгжүүлэлтийн туршилтын горим. Файлын input/File объект, OCR-д засварлаж амжаагүй textarea, audio editor-ийн хадгалаагүй interval нь UI reload үед алдагдаж болно. Бодит олон цагийн QA-д LIVE-г унтрааж, `START_BYBE.bat` ашиглана. JSON backup тогтмол хийнэ.

Windows нэг удаагийн эхлэх команд:
```bat
cd /d D:\bybe-studio\BYBE-new
git pull origin feature/typography-ocr-workstation
```
Одоо ажиллаж байгаа хуучин серверийг Ctrl+C-аар нэг удаа зогсооно. Дараа нь Windows File Explorer дээр `D:\bybe-studio\BYBE-new\START_BYBE_LIVE.bat`-ийг давхар товшиж асаана. Дараагийн commit-үүдэд CMD дээр гараар git pull/npm install бичих шаардлагагүй.

## Ажлын нэг товшилтын workflow
1. Эх видео нээх → OCR/Whisper/FFmpeg background processing автоматаар.
2. Засах аудионы мөрөө зүүн талд сонгох **эсвэл** доод waveform-аас [start,end] хүрээ чирж сонгох.
3. `T` (эсвэл `T · Бүтэн текст хүрээлэх`) → видео пауз, текст хүрээлэх давхарга идэвхжинэ. Шинэ [start,end] сонголт хийсэн бол энэ горим автоматаар идэвхжинэ.
4. Видео дээр хүссэн Чех өгүүлбэр/Англи өгүүлбэрийг бүхэлд нь хулганаар хүрээлнэ. OCR буруу эсвэл байхгүй бол текстийн талбарт өөрөө бичнэ.
5. `Текст хуулах` эсвэл `Сонгосон аудиотой холбох`; `Ctrl+Enter` холбоно, `Esc` хаана.
6. Зүүн жагсаалтаас ▶ сонсох, ✎ зааг засах, Delete/Trash хуурамч аудио мөрийг устгах, Ctrl+Z сэргээх.
7. Шаардлагатай WAV revision-г экспортолж 6 чанарын шалгалтыг хүн батлах хүртэл APP_READY биш хэвээр.
